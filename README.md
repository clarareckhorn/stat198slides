# dataviz-decal format

## Installing

```bash
quarto add clarareckhorn/dataviz-decal
```

This will install the extension.

## Format Options

This is a sample deck for the Stat 198 DataViz DeCal course. The features include:

1. Title slide with background image.
2. A bunch of yaml defaults.
3. Clickable logo in lower right.
4. No log or slide number on title slide.
5. Custom `:::poll` div for poll questions.
